# LaTeX & Math Formatting Rules

1. Không dùng inline LaTeX `$ ... $` chứa dấu `_`, `^`, hoặc `\text{...}` trong câu văn chat (tránh xung đột với Markdown italics `_..._`).
2. Thay vào đó dùng inline code: `T_race(S)`, `sum(l_k) = N_total`, `nabla t_deg(a) = d1 + 2*d2*a`, `D_pop < 0.15`, hoặc Unicode `∇t_deg`, `ΔN`, `α_fuel`, `γ_track`.
3. Chỉ dùng `$$ ... $$` dạng khối độc lập cho công thức quan trọng, không nhét chữ tiếng Việt vào `\text{...}` trong LaTeX.
4. Đảm bảo toàn bộ dấu ngoặc cân bằng 100%.
